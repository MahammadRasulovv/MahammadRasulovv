## Featured Projects

**[Credit Risk Assessment Pipeline](https://github.com/MahammadRasulovv/credit-risk-airflow-pipeline)**
End-to-end pipeline orchestrated with Airflow 3 across PostgreSQL, PySpark and MinIO. Uses SQL/File sensors, conditional branching and `SparkSubmitOperator`; processes credit applications via JDBC and DataFrame joins, applies rule-based risk classification with validation checks, and stores results as partitioned Delta Lake tables.
`Airflow 3` `PySpark` `PostgreSQL` `Delta Lake` `MinIO` `Docker`

**[Spark Lakehouse Pipeline](https://github.com/MahammadRasulovv/data-lakehouse-delta-iceberg-minio)**
7 PySpark ETL pipelines on a 2-worker Spark cluster with PostgreSQL JDBC and MinIO (S3). Processed 52,100 rows into 50,600 Silver records, compacted 200 Delta files into 10, and tested Iceberg MERGE and time travel.
`PySpark` `Delta Lake` `Iceberg` `MinIO` `PostgreSQL` `Docker`

**[Bank Customer Churn Analysis](https://github.com/MahammadRasulovv/bank-customer-churn)**
Normalized 3-table Oracle schema with PK/FK constraints, 8 composite indexes validated with EXPLAIN PLAN, and 17 analytical queries using window functions, DML and MERGE to uncover churn patterns.
`Oracle SQL` `PL/SQL` `Window Functions` `Indexing`
